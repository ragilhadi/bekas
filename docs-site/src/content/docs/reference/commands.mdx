Global options: `--profile TEXT`, `--json`, `-v/--verbose`.

## bekas audit

`--plugin`, `--serial`, `--sort-by [size|age|tier]`, `--top N` (list at most N candidates per plugin; totals are unaffected), `--no-cache`, `--rebuild-cache`. Read-only.

## bekas plan

`--safe-only`, `--include-review`, `--json`, `--save PATH`, `--top N` (list at most N candidates per category), `--no-cache`. `--safe-only` and `--include-review` cannot be combined.

## bekas clean

`--apply`, `--safe-only`, `--review`, `--yes-all`, `--non-interactive`, `--accept-categories`, `--plan-file`, `--force-stale`, `--allow-unsigned`. Dry run by default.

## bekas inspect

`bekas inspect <candidate_id>` — full reasoning for one candidate. It runs a fresh audit to find it, so an id from an earlier audit may no longer exist.

## bekas history

`bekas history [RUN_ID] [--since HOURS] [--json]`.

## bekas undo

`bekas undo [RUN_ID]` — restore quarantined items and report items that were permanently deleted. Safe to repeat; exits 1 if any item could not be restored, 3 if another bekas process holds the lock.

## bekas quarantine

`list`, `restore <id>`, `purge`. `restore` exits 1 on failure; `restore` and `purge` exit 3 if another bekas process holds the lock.

## bekas plugins

`list`, `enable <name>`, `disable <name>`.

## bekas config

`show [--resolved]`, `validate`.

## bekas doctor

`bekas doctor [--json] [--skip a,b]`. Checks: Python version, config, quarantine writable, undo DB, Docker, Git, plugins, free disk space, quarantine on the same filesystem. A missing or stopped Docker daemon is a warning, not an error. Exit code is non-zero if any check fails.

## bekas tui

Launch the interactive UI.
