## Confidence tiers

| Tier | Meaning | Example |
|---|---|---|
| `SAFE` | Easily recreated or fully reversible | dangling Docker image, `__pycache__` |
| `REVIEW` | May affect your workflow | old download, browser cache |
| `MANUAL` | High risk, explicit opt-in | branch on an active project |

## Protections

- **Read-only by default** — `audit` and `plan` never modify anything.
- **Dry-run by default** — `clean` needs `--apply`.
- **Hard exclusions** — system directories, `/`, `$HOME` itself and any folder that contains one of your protected paths, sensitive dotfiles, symlinks that leave `$HOME`, active virtualenvs and `.git` are never touched.
- **bekas's own data directory** is excluded, so quarantine contents are never cleaned by accident.
- **Non-local filesystems** (NFS, SMB, FUSE) and **symlinks leaving `$HOME`** are skipped.
- **Recently modified files** (within `min_quiet_hours`, default 6) are skipped.
- **Typed confirmation** for high-risk operations.
- **Signed plans** detect tampering.

The full list of exclusion rules is in [`docs/SAFETY.md`](https://github.com/ragilhadi/bekas/blob/master/docs/SAFETY.md).

## Your own exclusions

```yaml
exclude:
  - ~/code/keep-me
  - "*/important/*"
  - node_modules/keep
```

Patterns use gitignore-style matching: `*` stays inside one path segment, `**` crosses segments, a pattern without a leading `/` or `~/` matches at any depth, and excluding a directory also excludes everything inside it. Exclusions are checked again when a saved plan is applied, so adding one after `bekas plan --save` still protects that path.
